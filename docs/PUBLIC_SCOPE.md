# 公开范围、剩余缺口与可分发性

本候选来自远程私审包，原始项目未改动。远程目录的绝对部署路径只保存在私有审查材料；公开映射使用项目相对路径。

|处理|内容|理由|
|---|---|---|
|保留|dagrpo、tests、compat、必要scripts、平台入口|完整核心依赖链与真实工程实现；大部分字节不变|
|保留派生|标量评分、ID、数据manifest、统计、历史在线曲线|可重新统计；删去模型回答/真值/token序列和部署字段|
|新建|README/架构/复现/历史/求职/PDF/验证工具|改善公开交付；不是新算法或训练结果|
|排除|原始回答与少量私审题目、日志正文、PID/job文件、硬件主机记录|私有审查可用，不自动公开|
|排除|模型、Adam、缓存、虚拟环境、崩溃转储、重复大压缩包|体积、隐私、许可边界；不妨碍源码展示|
|外链|固定verl、Qwen、GSM8K及CUDA依赖|不重复打包完整第三方源码/权重|
|待核验|权重全量SHA、跨硬件确定性、安装/下载可用性、GPU重新运行|本轮缺材料或明确未运行|
|待核验|历史控制器归档版本|一处脚本哈希不符，旧源未交接；不认定无行为变化|
|未填写|正式项目标题、作者/版权人署名、GitHub目标URL|沿用现有包名作候选标识，不猜测个人身份/仓库|

已核对：私审包496文件内部完整性、无阶段A以来的已采文件变化、全参审计、17角色结果及原预测哈希、68条私有原回答样本重评分、manifest中3879 ID互斥。完整原预测由采集器在远程流式算hash，本轮只拥有评分投影及少量原行；哈希一致不等同于独立重跑模型验证。

本轮原始实验数据/冻结源码/历史验收清单保持原状。公开JSON重写/路径剔除/汇总均标记派生，`provenance/evidence-map.json`写提取规则和原证据hash，`derived-hashes.json`写公开产物hash；不会把公开摘要称原件。
